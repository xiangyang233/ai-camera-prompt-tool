# AI 绘画 3D 镜头视角提示词工具需求档案

版本：0.2 草案

更新日期：2026-10-27

项目名：AI Camera Prompt Tool

当前阶段：需求设计，尚未实现软件。

## 1. 产品目标

软件中放置一个具有明确正面、背面、左右侧面和顶部特征的真实 3D 参照模型。以模型中心为环绕中心，设置一台与中心距离可调的虚拟相机。用户通过鼠标让相机绕模型转动、调整俯仰和拉近拉远，查看实际取景，并根据相机最终状态生成 AI 绘画提示词。

核心流程是“摆镜头 → 看取景 → 得到提示词”。真实 3D 模型、鼠标环绕和相机取景预览均为首版必需功能。预设和参数输入作为辅助，与鼠标控制同步。

首版暂定为中文界面、桌面浏览器优先的 Web 应用，在 Windows Edge 和 Chrome 中运行。3D 渲染和提示词拼装在本地完成，无需登录或模型 API。

## 2. 3D 参照模型

- 使用有体积、有深度的 3D 网格，不能以始终朝向相机的平面图片替代。
- 首版内置原创低面数非对称人形或机器人：正面有五官，背面有背包，左右肩有不同形状的配件，顶部与底部有可区分结构。具体造型在开发时细化。
- 角度辨识同时依靠形状和颜色，不能只靠颜色或文字。从正面、背面、左右侧面、斜侧面及高低视角观察，均可看到合理的形态变化。
- 模型保持位置和朝向不变，用户操作相机。空间总览显示模型中心、辅助网格及前后左右标记。
- 模型只是机位参照，不代表最终绘画主体。提示词不得自动带入机器人的外观、配件或颜色。

## 3. 环绕相机与鼠标操作

模型加载后确定固定环绕中心，默认采用模型包围盒中心。相机围绕该点运动并始终朝向该点，保持画面上方稳定。首版不提供自由平移、自由偏转和画面滚转，避免操作中意外改变环绕中心。

| 操作 | 相机行为 | 界面反馈 |
| --- | --- | --- |
| 左键水平拖动 | 围绕模型中心水平旋转，可连续环绕 360° | 取景、水平角度和提示词同步变化 |
| 左键垂直拖动 | 调整相机高度角，实现俯拍和仰拍 | 俯仰角、取景和提示词同步变化 |
| 鼠标滚轮 | 改变相机与中心的距离，拉近或拉远 | 距离和取景范围变化；默认不改变焦距 |
| 滑杆或数值输入 | 精确设置角度和距离 | 与鼠标控制双向同步 |
| 点击机位预设 | 应用方位、俯仰、距离和焦距组合 | 更新真实机位、取景和输出 |
| 点击重置 | 恢复默认机位、距离和焦距 | 完整模型重新可见 |

距离范围按模型尺寸设置，显示相对距离或场景单位，不无依据标为真实米数。最小距离需避免相机进入模型，最大距离需保持模型可辨认。具体上下限在原型中结合模型和焦距验证；允许近距离构图裁切，但相机不能穿入模型。

俯仰范围首版暂定 −85° 至 +85°，支持接近正上方和正下方观察，避免极点翻转。地面辅助网格不得遮挡低机位主体；精确 ±90° 极点视角后续单独设计。

## 4. 页面与使用流程

大型 3D 主视口显示输出相机实际看到的模型；旁边展示相机参数和提示词。小型空间总览标记模型中心、相机位置及朝向，帮助理解机位。总览的观察相机不参与提示词计算。

1. 打开软件，看到完整模型、默认取景和鼠标操作说明。
2. 拖动鼠标环绕和调整俯仰，滚轮改变距离，找到想要的画面。
3. 查看角度、距离、焦距和自动识别的景别，必要时通过数值微调。
4. 输入可选主体描述，选择中文或英文镜头措辞。
5. 复制镜头片段或完整提示词，也可手动编辑、导出 TXT。

## 5. 首版功能范围

| 优先级 | 功能 | 要求 |
| --- | --- | --- |
| P0 | 真实 3D 模型 | 一个各方向可辨识的非对称模型，配有基础材质、光照和固定朝向 |
| P0 | 环绕相机 | 水平环绕、俯仰、距离调整、边界限制和重置 |
| P0 | 取景与空间总览 | 显示真实相机画面，并标记模型中心和机位 |
| P0 | 参数同步 | 鼠标、滑杆、数值输入、预设、取景和提示词共享相机状态 |
| P0 | 焦距 | 默认 50mm，提供 24、35、50、85mm；统一虚拟传感器约定后计算视场角，实际预览同步变化 |
| P0 | 提示词 | 根据相机方位、俯仰和实际取景生成中英文镜头描述，支持可选主体原文 |

## 6. 相机到提示词的规则

### 坐标与状态

以模型固定朝向为基准：水平角 0° 为正面，90° 为主体左侧，180° 为背面，270° 为主体右侧。总览明确标记主体左右。俯仰角 0° 为相机与中心等高，正值表示相机在中心上方并向下看，负值表示在下方并向上看。

内部保存相机位置、目标、方位角、俯仰角、距离、焦距、画幅比例和模型尺寸。实际预览与提示词均由这份状态派生，总览观察相机不得覆盖输出相机的数据。

### 文本生成

- 水平方位映射为正面、左前四分之三、左侧面、左后四分之三、背面、右后四分之三、右侧面和右前四分之三等描述。
- 俯仰映射为平视、俯拍、仰拍、接近正俯视、接近正仰视。角度区间集中配置，在边界设置容差，防止轻微拖动导致词语反复跳变。
- 景别根据模型在实际画面中的投影占比、可见范围和裁切判断，结合焦距、距离与画幅比例；不能只按距离或焦距分类。首版使用全景、中景、近景等粗粒度描述，不能把躯干裁切误称为面部特写；无法可靠判断时允许省略景别。
- 默认拼装顺序：主体 → 景别 → 水平方位 → 俯仰视角 → 焦距。距离与精确角度显示在参数区，不强制塞入通用提示词。
- 主体文本保留原文；语言切换只转换内置镜头术语，不承诺离线翻译任意主体输入。
- 拖动时自动生成区实时更新；手动编辑使用独立文本区，提供“使用当前镜头重新生成”按钮显式替换，不随拖动被覆盖。
- 使用通用自然语言，不添加特定模型的权重或触发词；同一相机状态和词库版本产生相同输出。
- 3D 预览准确表达本软件的机位；绘图模型执行文本的能力不同，提示词不保证 AI 成图精确还原视角。

示例：相机位于主体左前方、高于模型中心，实际取景识别为中景，焦距为 50mm。

```text
中景，从主体左前方观察的四分之三视角，俯拍，50mm 镜头
```

```text
medium shot, three-quarter view from the subject's left front, high-angle shot, 50mm lens
```

## 7. 实现建议

建议采用 React、TypeScript、Vite 和 Three.js，从第一版实现真实 3D 渲染。初始模型可由原创基础几何体组合，明确记录朝向与尺寸，之后再替换为精细模型。

渲染、相机状态、角度与景别分类、双语词库分别维护。分类规则能脱离界面测试，覆盖角度跨越 0°/360°、分类边界、距离限制和裁切。WebGL 不可用时给出明确提示，不能用静态图片冒充已实现的 3D 功能。

## 8. 验收标准

1. 从正面、背面、左右及上下斜视角观察，模型有可辨识的几何差异，不是随相机转向的平面图片。
2. 仅靠鼠标即可完成水平一周环绕、俯仰、拉近拉远，并获得对应提示词。
3. 环绕时模型不转动、中心不漂移；滚轮改变距离而不改变焦距。
4. 相机到达距离和俯仰边界时稳定停止，不穿入模型、不突然翻转；重置后完整模型可见。
5. 四个标准方位的读数、总览、实际取景与中英文输出一致；跨越 360° 无异常跳变。
6. 相同距离下切换焦距，取景范围实际变化；景别随画面变化，裁切不被误判为完整全身或面部特写。
7. 拖动时预览跟手、参数与自动提示词持续更新，松开后保留最终状态；边界轻微移动不导致术语闪变。
8. 至少 8 个预设可还原真实机位；手动编辑不被拖动覆盖；复制和导出与所选文本一致。
9. 无主体输入也可输出镜头片段；参照模型的背包、颜色等不写入主体描述。
10. 在 Windows Edge、Chrome 的 1280×720 和 1920×1080 视口检查主要流程；窄屏可纵向排列，首版鼠标交互以桌面为验收重点。
11. P1 完成后，收藏刷新可恢复；无效 JSON 导入不破坏已有数据。

## 10. 开发顺序

- M0：更新需求与 README，明确 3D 模型、环绕相机和取景输出流程。
- M1：实现真实 3D 场景、可辨识模型、鼠标环绕、距离与俯仰限制、实际取景和空间总览。
- M2：加入参数同步、焦距、预设、中英文提示词、编辑与复制导出，完成全部 P0 验收。
- M3：增加收藏、备份和更多模型，再评估专用提示词格式、自定义取景目标与桌面打包。
