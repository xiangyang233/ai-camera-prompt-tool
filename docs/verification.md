# 核心首版验证记录

日期：2026-10-27。

## 角度键盘输入更新

- 水平环绕与俯仰增加数字输入框，支持 0.1° 精度，输入时同步相机与提示词，回车或失去焦点后显示规范化值。
- 应用内浏览器实测：123.4°、−25.5° 与滑杆同步；450° 折算为 90°；−100° 俯仰限制为 −85°；清空后回车恢复最近有效值；滑杆 Home 操作回写数字框为 0°。
- 输入途中保留负号、小数等临时文本，不被渲染更新覆盖。无效或空值不会写入相机状态。

## 详细提示词更新

- 由短标签拼接改成简洁自然语言，补充可见侧面、俯仰程度、取景范围与居中构图；不自动生成外观、灯光、风格或平台参数。
- 实际屏幕投影决定上、下、左、右边缘是否发生裁切，避免同时输出完整主体与裁切描述。
- 零俯仰相机对准主体中心，英文使用 level shot；+8° 等轻微俯仰单独描述，避免误写为 eye-level shot。
- 7 项测试通过，新增实际裁切边缘、俯仰极值、斜侧面描述、通用性与长度检查。类型检查和生产构建通过。
- 在当前应用内浏览器中验证中文近距离提示词，实际输出“上、下边缘”裁切说明，且与滑杆和当前取景同步。
- 未调用付费或外部绘图模型进行成图对比；本轮验证文本与机位一致性，不保证不同生成模型完全复现视角。

表述设计参考 [Midjourney Prompt Basics](https://docs.midjourney.com/hc/en-us/articles/32023408776205-Prompt-Basics) 与 [BFL FLUX.2 Prompting Guide](https://docs.bfl.ai/guides/prompting_guide_flux2) 对清晰、具体表述的建议。具体方位和裁切规则由本项目相机状态计算。

## 浏览器实际操作

在本机 Edge 中检查：

- 默认模型正确显示五官、服装、贴图和新增配件；背面机位显示背包和后脑。
- 从背面用鼠标拖动到约 268°、俯仰 +24°，实时提示词对应主体右侧和俯拍。
- 在取景区滚轮操作将距离由 2.85 倍改变到约 3.57 倍，角度保持不变。
- 俯仰滑杆可达到 +85°，中文模式及主体文本能够进入输出。
- 点击复制后，读取剪贴板确认与显示文本一致。
- 收紧最近距离至 1.25 倍模型高度后，重新检查 +85° 俯视，模型表面正常显示，无穿模；重置回到完整取景。

本轮实测使用 Edge 的当前桌面窗口。固定分辨率检查因浏览器控制连接中断未完成，尚未单独验证 Chrome；未宣称通过完整跨浏览器或窄屏验收。
