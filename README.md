# AI Camera Prompt Tool

面向 AI 绘画的镜头视角提示词工具。计划通过中文参数选择和可视化示意，输出可复制的中英文镜头描述。

当前阶段：需求与仓库初始化，尚无可运行的应用。

## 项目文档

- [需求档案](docs/requirements.md)：产品目标、首版范围、输出规则、验收标准和同类工具参考。

## 计划功能

- 景别、水平视角和俯仰角选择。
- 原创镜头示意与常用预设。
- 中英文镜头提示词、复制和 TXT 导出。
- 后续补充焦距、构图和本地收藏。

暂定技术方案为 React、TypeScript、Vite，核心提示词生成在浏览器本地完成。具体实现以需求档案及后续讨论为准。
