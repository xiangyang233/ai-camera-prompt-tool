# AI Camera Prompt Tool

面向 AI 绘画的 3D 镜头视角提示词工具。用户围绕各方向均可辨识的立体模型，用鼠标调整相机角度和距离，查看实际取景，再获得中英文镜头提示词。

当前阶段：需求设计，尚无可运行应用。

## 项目文档

- [需求档案](docs/requirements.md)：3D 模型、鼠标环绕交互、输出规则、验收标准与同类工具参考。

## 计划功能

- 原创非对称 3D 模型，正面、背面、左右及上下视角有辨识特征。
- 以模型中心为目标，鼠标拖动环绕和俯仰，滚轮改变相机距离。
- 真实相机取景、空间总览、焦距与机位参数同步。
- 根据实际相机状态生成中英文镜头提示词，支持编辑、复制和 TXT 导出。
- 后续增加本地收藏、参数备份及更多参照模型。

暂定采用 React、TypeScript、Vite 和 Three.js，3D 渲染与提示词生成在浏览器本地完成。真实 3D 模型与鼠标环绕相机是首版必需功能。
