# 取景 · AI Camera Prompt Tool

**先摆镜头，再复制提示词。** 取景是一个轻量、开源的 AI 绘画镜头提示词工具：围绕可辨认正面、背面和左右侧面的 3D 人物调整相机，把所见的取景转换成中英文摄影描述。

适合需要表达人物视角、俯仰、景别和焦距的绘画创作者。你可以用鼠标寻找角度，也可以直接输入角度、距离和焦距。工具在浏览器本地运行，无需账号、API 密钥或后端；它生成镜头提示词，不直接生成图片。

**最新更新：** 已支持角度、距离与焦距数值输入，以及近似角度、画面占比和实际裁切说明。焦距范围为 18～200 mm。完整变更见 [更新日志](CHANGELOG.md)。

## 使用流程

1. 按下方说明启动本地服务，在浏览器打开工具。
2. 左键拖动环绕主体，滚轮调整距离，或直接输入角度、距离与焦距。
3. 查看实时取景；可选填自己的画面主体，并切换中文或英文输出。
4. 点击“复制提示词”，粘贴到常用 AI 绘画工具中。

例如，相机位于左前方、俯拍 20°、焦距 50 mm 时，描述会包含：

> 从主体正前方朝主体自身左侧环绕约 30°，同时呈现正面和左侧。俯拍，相机高于主体中心，向下拍摄，视线相对水平向下约 20°。主体居中，镜头指向主体中心，50mm 标准镜头。

完整输出还会根据当前取景补充景别、主体高度占比和裁切边缘。输入主体保留原文；模型的服装、配件与灯光不会自动进入提示词。

## 运行

建议使用 Node.js 24+；本项目已在 Node.js 24.12.0 验证。

```sh
npm ci
npm run dev -- --port 5173
```

打开终端输出的本地地址，默认是 http://127.0.0.1:5173/ 。无需 API 密钥、账号或后端。模型和贴图随项目提供，运行时无需访问资源提供方。

```sh
npm test
npm run build
npm run preview -- --port 4173
```

`dist/` 为可部署的静态文件。请通过 HTTP 服务打开，不要直接双击 HTML。

## 核心功能

- 左键拖动：水平环绕和俯仰；滚轮：改变与模型中心的距离。
- 水平与俯仰角可直接键盘输入（支持 0.1°），也可拖动滑杆；输入时预览更新，回车或移开焦点确认。水平角自动折算至 0°～360°，俯仰限制为 ±85°；空输入恢复最近有效值。
- 镜头距离同样支持直接输入，精度为 0.01 倍模型高度，与滑杆、滚轮同步；超出范围自动限制在可用上下限，清空后确认恢复最近有效距离。
- 焦距支持滑杆与数值输入（18～200 mm，精度 0.1 mm），即时改变取景范围、占比与提示词，重置恢复 50 mm。焦距调整不移动相机。
- 角度、距离滑杆与真实取景同步；提供四个方向入口和重置。
- 机位以约 5° 为步长输出近似方位角和视线俯仰角，左右以主体自身为准。距离转换为实际投影的画面高度占比（约 5% 步长）；裁切时仅计算可见部分，并注明裁切边缘。输入与 3D 相机仍保留原有精度，量化只用于提示词。
- 输出通用中英文镜头提示词：明确相机方位、可见侧面、俯仰程度、完整取景或实际裁切边缘，并包含居中构图、所选焦距及广角／标准／长焦描述。可添加主体原文，一键复制。
- 聚焦取景区后，方向键微调，Shift 加速，加减键改变距离，Home 重置。

首版只实现核心功能。焦距默认为 50mm，可在 18～200mm 间调整（固定 24mm 传感器高度，用于统一视场角计算），俯仰范围为 ±85°，距离为模型高度的 1.25～4.5 倍。模型保持静止，相机朝向整体中心；近距离主要用于中心局部取景，不提供面部自动对焦。景别由模型顶点的屏幕投影粗略分类，AI 成图对视角的遵循程度取决于所用绘图模型。

## 轻量实现

原生 TypeScript、Three.js 和 Vite；仅 Three.js 为运行时依赖，无 React、组件库、外部字体、云服务或动画循环。鼠标、参数或窗口变化时按需渲染，像素比上限 1.5。

模型采用 Kenney Blocky Characters 2.0 的静态 OBJ（7,328 字节）和单张贴图（20,171 字节），避免加载不使用的骨骼和动画。模型许可为 CC0；新增左侧小挎包用于辨认左右。
